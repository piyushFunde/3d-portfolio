# I Built a Portfolio Because Apparently GitHub Wasn't Enough

At some point, you realize that saying "check my GitHub" isn't a complete answer.

I had projects scattered across repositories, deployment links saved in random tabs, screenshots hiding in folders, and a resume trying its best to explain everything in one page.

So I decided to put it all in one place.

Naturally, I built another project to showcase the projects I had already built.

Very developer of me.

## Why I Built This

I wanted a place that felt more personal than a resume and more organized than a GitHub profile.

A place where I could show not just what I built, but why I built it.

Some projects started as ideas.

Some started as problems I wanted to solve.

And some started with the classic:

"How hard can this be?"

Spoiler: usually harder than expected.

### Why Space Theme?

Because why not? If I'm going to write about code, I might as well do it while floating in the void of the internet. Plus, dark mode is default in space.

## What's Next?

I'll keep adding projects, experiments, and lessons as I continue growing as a developer.

Maybe this portfolio will change a lot over time.

I hope it does.

Because if it still looks exactly the same a year from now, it probably means I stopped building things.

And I don't plan on doing that.

## Conclusion

Welcome to the work in progress. 🚀
